This Linux Basics cheat sheet summarizes the essential terms, filesystem structure, and terminal commands covered in the chapter.

**Key Concepts & Filesystem**

* **root:** The superuser administrative account with full system privileges.
* **binaries:** Executable applications or tools residing primarily in `/bin`, `/sbin`, `/usr/bin`, or `/usr/sbin`.
* **/** (Root): The base node of the entire Linux filesystem tree.
* `/root`: The home directory reserved specifically for the root user.
* `/home`: Default directory housing personal files for standard users.
* `/etc`: Holds core system and application configuration files.
* `/mnt` & `/media`: Attachment points for temporary filesystems, external drives, and media.

**System Information & Navigation**

| Command | Action | Example |
| --- | --- | --- |
| `pwd` | Print present working directory path | `pwd` |
| `whoami` | Display active user account name | `whoami` |
| `cd <path>` | Change active directory | `cd /etc` |
| `cd ..` | Move up one directory level | `cd ..` *(or `cd ../..` for two levels)* |
| `cd /` | Jump directly to root directory | `cd /` |
| `ls` | List directory contents | `ls` |
| `ls -l` | Display detailed list (permissions, size, owner) | `ls -l` |
| `ls -la` | List all contents, including hidden files | `ls -la` |

**Help & Manuals**

| Command | Action | Example |
| --- | --- | --- |
| `--help` / `-h` | Output basic command usage and flags | `aircrack-ng --help` |
| `man <cmd>` | Open detailed system manual page (`q` to exit) | `man aircrack-ng` |

**Searching & Output Filtering**

| Command | Action | Example |
| --- | --- | --- |
| `locate <term>` | Fast system-wide search via indexed database | `locate aircrack-ng` |
| `whereis <cmd>` | Find binary, source, and manual page paths | `whereis aircrack-ng` |
| `which <cmd>` | Find binary location restricted to `$PATH` variable | `which aircrack-ng` |
| `find <dir> -type f -name <file>` | Search filesystem tree by specific attributes | `find /etc -type f -name apache2.*` |
| `<cmd> | grep <pattern>` | Pipe output of a command to filter for keywords | `ps aux | grep apache2` |

**File & Directory Management**

| Command | Action | Example |
| --- | --- | --- |
| `cat > <file>` | Write/overwrite a file (`Ctrl+D` to save & exit) | `cat > note.txt` |
| `cat >> <file>` | Append text to the end of an existing file | `cat >> note.txt` |
| `touch <file>` | Create a blank file or update file timestamp | `touch script.py` |
| `mkdir <dir>` | Create a new directory | `mkdir tools` |
| `cp <src> <dest>` | Copy file or directory to a destination | `cp note.txt /tmp/note.txt` |
| `mv <src> <dest>` | Move or rename a file/directory | `mv old.txt new.txt` |
| `rm <file>` | Delete a file | `rm script.py` |
| `rmdir <dir>` | Delete an **empty** directory | `rmdir tools` |
| `rm -r <dir>` | Recursively delete a directory and its contents | `rm -r tools` |

**Wildcard Reference**

* `*` Matches zero or more characters (e.g., `*at` finds `cat`, `chat`, `flat`).
* `?` Matches exactly one character (e.g., `?at` finds `cat`, `hat`, but not `what`).
* `[]` Matches any single character enclosed in brackets (e.g., `[cb]at` finds `cat` and `bat`).
